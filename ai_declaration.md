# AI-DECLARATION

## Purpose
We have partly utilized generative AI for this project to aid the development of difficult, more technical features, to summarize and understand the changes to the code base made by each other, and finally to improve the UI-aesthetics for a few areas.


## Work Phase
The project started off handcraftet by following a youtube tutorial on flask and sql-alchemy, and manually writing to organisations to get access to the datasets for synthesis. Only later has AI been used to enhance and aid our features.


## Extent of Use
We have utilized classic LLMs such as ChatGPT, Gemini, etc. but have refrained from using harness-based, more agentic llms for writing code. Instead, we have used these exclusively to understand the codebase and the changes everyone has made when convenient.


### Note on Project Integrity
For certain areas such as E/R modelling, database decomposition, idea creation, backend-structure and more areas core to the integrity of this project, we have intentially written these in hand to ensure full understanding of the learning-outcomes this project brings.

Instead we have focused the use of GenAI-assistance on more impressive though unnecessary features which are not at the heart of the project and its learning-objectives itself.
