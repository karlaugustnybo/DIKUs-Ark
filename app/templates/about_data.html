The data behind the webside

We used many different datasets in the creation of this web app. Here's a list:

  • Genomes on a Tree (GoaT)

    Supplies comprehensive metrics regarding DNA sequencing status across individual species and the broader Tree of Life (ToL).

  • International Union for Conservation of Nature (IUCN)

    Yields tabular data on categorical extinction risks via the Red List of Threatened Species, as well as high-resolution spatial data layers containing geographic polygons.

  • Global Biodiversity Information Facility (GBIF)

    Serves as the central backend anchor, utilizing the GBIF Backbone Taxonomy to map and join disparate records under verified taxonomic keys.

  • EDGE of Existence

    Infuses evolutionary distinctiveness metrics combined with global threat assessments to capture evolutionary value.

  • GISCO (Eurostat)

    Provides high-fidelity geospatial templates defining the strict boundary intersections between Denmark's territorial landmass and marine waters.

How species has dna was calculated

Order Condition Result
1 redlist_category IN ('EX', 'EW') true
2 sample_acquired IS NOT NULL OR in_progress IS NOT NULL true
3 ebp_standard_criteria IS NOT NULL true
4 assembly_level IN ('Chromosome', 'Complete Genome') AND busco_completeness >= 90.0 true
5 Default Fallback false

It should also be noted GoaT takes precedence over IUCN for genus and family names. So they match with our ToL. Though scientific names for species are from IUCN.

#

How the Priority Score is calculated

Priority = Threat Score × DNA Level Score
Threat Score = slider value for the species' IUCN category.
DNA Level Score = slider value for the highest missing DNA level.
The default values are:

IUCN Default
Critically Endangered 4.0
Endangered 3.0
Vulnerable 2.0
Near Threatened 1.0
Data Deficient 2.0
Least Concern 0.1
GOAT Default
Missing Species DNA 2.0
Missing Genus DNA 3.0
Missing Family DNA 4.0
Already Sampled 0.0

Other remarks

Deduplication

Some species with the same GBIF ID have multiple rows in the IUCN datasets. The duplicates are removed and the one with the most conservative IUCN category is kept (eg. CR > EN).

Regex Search

The search box uses regexp_matches, not substring search. Example searches could be ^Canis, ensis$ or ^(Ardeidae|Rallidae|Rosaceae)$. Both species_name and family is searchable.

System classification

We use the IUCN tabular datasets system column to determine what species are in what system. If a species is both in Terrestrial and Marine, then its kept for both of these systems. On top of this we only render cells on land for Terrestrial and Freshwater, and in the sea for Marine (if a cell touches the land or sea its counted as that). This way its easier to distinguish important areas, instead of the coast having the highest priority score, because both Marine, Freshwater and Terrestrial normally are counted there. The map is renormalized for each system.
